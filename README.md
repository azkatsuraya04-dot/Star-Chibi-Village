# ⭐ Star Chibi Village

A cute 2D chibi pet life simulation game.

## 🎮 Features

- 🏠 Explore the village
- 🐾 Interact with cute animal characters
- 🛍️ Shop for items
- 🌱 Plant Star Plants
- ⭐ Harvest Star Plants
- 💰 Collect coins
- 🚿 Take care of your pet
- 🎵 Background music and sound effects

## 🛠️ Built With

- HTML
- CSS
- JavaScript
- Google AI Studio

## 🎯 About

Star Chibi Village is a simple 2D life simulation game created as a school project.
